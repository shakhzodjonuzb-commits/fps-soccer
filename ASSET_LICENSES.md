# Asset and license notes

## Original project content

The pitch, markings, goal geometry, stadium structures, crowd instances, advertising boards, ball appearance, team kits, player geometry, and procedural player numbers are generated by the source code in this repository. They are original procedural assets; no third-party player likenesses, club crests, league marks, or commercial game assets are bundled.

The sound layer in `src/game/audio/StadiumAudio.ts` synthesizes ambience and simple effects using the Web Audio API. No music, crowd recordings, whistle recordings, or other external audio files are bundled.

## Third-party runtime libraries

The project depends on Three.js, Rapier, Capacitor, Vite, TypeScript, and Vitest. Their license texts and notices should be reviewed from the exact installed package versions before redistribution. This repository does not copy their source code into the project asset folders.

## Not yet included

No GLB/GLTF player models, skeletal animation clips, stadium scans, texture packs, recorded sound packs, or third-party fonts are included. Consequently, the current player locomotion is procedural and is not a substitute for the requested rigged animation set. Any future asset addition must be accompanied by its source, license, attribution requirements, and redistribution permission here.
